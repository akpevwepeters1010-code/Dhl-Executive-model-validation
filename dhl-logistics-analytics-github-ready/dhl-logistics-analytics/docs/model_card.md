# Model Card

## Intended use

Early warning of shipment SLA-breach risk before last-mile dispatch.

## Users

Dispatchers, operations analysts, ML engineers and governance teams.

## Target

Binary indicator of whether final delivery exceeds the contractual SLA.

## Reported capstone model

The supplied report reports XGBoost results of:

- Accuracy: 94.1%
- Precision: 84.2%
- Recall: 89.4%
- F1: 86.7%
- ROC-AUC: 0.958

These figures belong to the capstone analysis and should not be treated as measurements of the demo model generated by this repository.

## Limitations

- The original enterprise dataset is not included.
- Operational conditions can change.
- Regional representation may be unequal.
- False negatives remain operationally important.
- Model recommendations require human validation.
